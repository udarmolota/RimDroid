Quick start

RimDroid is a launcher: it runs your own copy of RimWorld on Android. The game itself is not included.

  1. You need to own RimWorld on Steam or GOG. RimDroid runs the Linux version of the game, RimWorld 1.5 or 1.6.
  2. Get the game into the app. With Steam, open the side menu and tap Steam Downloads: the game downloads straight into a ready instance. For GOG and the other ways, see Getting the game.
  3. An instance is one installed copy of the game. Each one has its own card on the main screen and its own settings behind the gear icon. You can keep several, for example 1.5 and 1.6 side by side.
  4. When an instance is created, RimDroid detects your phone's GPU and picks a matching graphics driver by itself.
  5. Tap the ▶ button on the card. The first launch takes longer while the game prepares its files. Do not press Back while it loads.

You need Android 11 or newer, a 64-bit phone and at least 6 GB of RAM (8 GB or more for comfortable play), plus 5–10 GB of free storage.

The ? at the top of each screen opens this page at the part about that screen.

Something went wrong? See Reporting a problem.

Getting the game

RimDroid needs the Linux version of RimWorld, from a store where you own the game. Pick one of the ways below.

1. From Steam, in the app

  1. Open the side menu and tap Steam Downloads, tab Game.
  2. Choose RimWorld 1.5 or RimWorld 1.6 and enter a name for the new instance.
  3. Sign in with your Steam account. Your login goes to Steam only and is not stored. Approve the sign-in in the Steam Mobile app, or enter the Steam Guard code.
  4. Tap Download. The game goes straight into a new instance: no PC and no archives needed.
  5. If the download stops, start it again with the same instance name and it continues where it stopped.

To get an older build instead of the recommended one, enter its Manifest ID in the advanced field (the IDs are listed on SteamDB). Otherwise leave it empty.

2. From GOG

  1. Open the side menu and tap Sign in to GOG. Sign in with your GOG e-mail and password on GOG's own page: RimDroid never sees your password.
  2. Signing in through a linked account, such as Google, does not work inside an app. If that is how you normally log in, set a GOG password first: gog.com → Sign in → Password reset.
  3. Tap Check library. RimWorld appears as a card, with its DLC below it.
  4. Tap Download on the game and on every DLC you want. The files download one after another into the public Download/RimDroid folder; allow All files access when asked. You can switch to other apps meanwhile. If a download stops, tap the button again to continue.
  5. Once the game is downloaded, its button becomes Create an instance. The new instance gets the game together with every DLC you have already downloaded.
On a PC

In your library on gog.com, download the Linux installers (.sh files) of RimWorld and of the DLC you own. Pack them all into one .zip archive, copy it to the phone and add it as described in From a .zip archive. The .zip is needed because file managers do not reliably hand a bare .sh file to apps.

3. From a .zip archive

Open the side menu and tap Add game instance, or the + at the top of the main screen. Enter a name, tap Pick ZIP file, choose the archive and tap Install.

  • The .zip can hold the RimWorld Linux build, the one with the RimWorldLinux file (a folder around it is fine, RimDroid finds it), or GOG's .sh installers of the game and its DLC.
  • Keep the name short: Latin letters and digits, up to 40 characters.
  • Keeping the .zip is not required, but it is handy later to reinstall or to create another instance of the same version.

DLC

  • From Steam: in Steam Downloads, tab DLC, tick the DLC your account owns and tap Download selected DLC. Each one is saved as a .zip in Download/RimDroid.
  • From GOG: download it from its card in Sign in to GOG, then tap Install on the same card. A DLC downloaded before you create the instance is included in it automatically.
  • To install a DLC file, open the side menu, tap Install mod / DLC, choose the file and the instance, open the DLC tab and tap Install. GOG installers are recognised by themselves.
  • A DLC must match the game version of the instance: a DLC for 1.6 goes into a 1.6 instance. That is why the install screen always asks you to choose the instance.

Mods

  • Steam Downloads, tab Mods, downloads Workshop mods by ID: the number at the end of the Workshop link (…/filedetails/?id=NUMBER). No Steam login needed; several IDs can be separated by spaces. Each mod is saved as a .zip in Download/RimDroid. Download via browser on the same tab opens a third-party site instead.
  • Install them in the side menu, Install mod / DLC, tab MODS. RimDroid finds the mod's real folder (the one with About/About.xml) inside any .zip.
  • Mods that need Harmony work: add the Harmony mod itself, as on a PC.
  • Mod lists of up to about 50 mods have been tested. Bigger lists are untested territory.
  • Manage Storage in the ⋮ menu of an instance card opens that instance's folder in your phone's file manager, if you want to add or remove files by hand.
  • If Chinese, Japanese or Korean text does not show, install the RimDroidCJKmod font mod: add the .zip with Install mod / DLC, tab MODS, then turn it on in the game's Mods menu. It needs no other mods.

Renderers and drivers

A renderer translates the game's desktop graphics for Android. Pick it in the instance settings (gear icon), card Video.

Zink ZFA (Vulkan)

The default and the recommended one. It draws through your phone's Vulkan driver, chosen right below it.

MobileGlues (no Vulkan)

Draws through the phone's OpenGL ES driver instead and needs no Vulkan at all. Experimental. Try it if Zink gives a black screen or a broken picture; it can help on phones without a Snapdragon (Adreno) GPU.

Vulkan drivers (for Zink)

When you create an instance, RimDroid picks a driver for your GPU, and Recommended driver (detect GPU) does the same again. If the picture looks wrong or stays black, try another one.

  • System (phone driver): the phone's own driver. Works on any GPU and is the right choice on phones without a Snapdragon (Adreno) GPU.
  • Turnip and Freedreno: open-source drivers for Snapdragon (Adreno) GPUs, each built for the GPU generation named in the list (6xx, 7xx, 8xx, 830/840).
  • Turnip Adreno 7XX_new (v26.2): the first one to try on Adreno 7xx when the screen stays black.
  • Turnip Adreno 6xx (legacy): for older Adreno 6xx GPUs, such as the one in the Snapdragon 685.
  • Custom driver (imported): your own driver. Import it in the side menu, Custom Vulkan driver (a .so file or an AdrenoTools .zip). It is then shared by all instances.

Picture and frame rate

All of these are in the instance settings (gear icon).

  • Render resolution: a lower resolution gives more FPS on weak GPUs and a bigger interface; fullscreen at the phone's own resolution is the sharpest. Black margins 1280×720 is the fastest.
  • Texture compression shrinks textures to save memory and gain FPS, and is needed to load several DLC on weaker phones. It mainly affects plants and resources; pawns and animals are never touched. Low is a good balance, Ultra low is a bit faster but plants look blurry.
  • Show FPS counter puts the frame rate in the top-left corner.
  • Frame rate limit (30, 60 or no limit) smooths out swings and leaves more of the processor to the game, which can raise the game speed on weaker phones. Try 60 or 30 if the counter jumps around.

Controls

Touch

  • Tap for a left click.
  • Hold a finger still for a moment for a right click, which gives orders such as "move here". A short vibration confirms it.
  • Pinch with two fingers to zoom.
  • Move the camera with the left stick. To drag the map with one finger instead, turn on Drag the map with a finger to pan in the instance settings.

On-screen controls

  • The default layout has a stick for the mouse cursor, a stick for the camera, left and right click buttons, Esc, Space (pause), game speeds 1–3 and the game's hotkeys. V hides and shows the controls; KB opens the phone's keyboard.
  • Change them in the instance settings, Edit on-screen controls: tap an element to select it and drag it to move it. Add creates buttons bound to any key or mouse action; Reset returns to the default layout.
  • Export controls layout and Import controls layout in the side menu share a layout as a .json file.

Typing

To type in the game, for example to rename a colonist, tap the text field, then KB: the phone's keyboard opens and what you type goes into the game. Tap KB again to close it. This works on RimWorld 1.6 only, and types Latin letters only.

Gamepad, mouse and keyboard

  • A physical gamepad works: the right stick moves the cursor, the left stick moves the camera, the triggers click and the bumpers zoom. If buttons are swapped, fix them in the instance settings, Gamepad mapping: tap Start and press the button you want for each action.
  • A physical mouse and keyboard work too.
  • The game always runs in landscape. Mirror the picture (180°) flips it for a gamepad or cradle that holds the phone the other way up. It applies from the next launch.

Saves and settings

  • Export saves and Import saves in the side menu move an instance's saves out and in as a .zip: for a backup, or to carry them to another instance or phone.
  • Export settings and Import settings do the same for the game's settings: options, key bindings, the mod list and mod settings.
  • Steam Cloud saves: if you also play RimWorld on a PC through Steam, this brings your cloud saves onto the phone and sends the phone's saves back. The sign-in is approved in the Steam Mobile app, so Steam Guard must be on there. When the same save exists on both sides, you choose which one to keep. Close the game before sending.

Compatibility mode

In the instance settings, card Advanced (tap its title to open it). Turn it on if the game will not start: a black screen, or stuck on loading. The game runs a bit slower with it, so leave it off when you do not need it. It is a workaround and may not help on every phone.

The same card has Debug mode, which writes a more detailed log, and Environment variables. Leave both alone unless we ask you to change them.

Native ARM64 Mono

In the instance settings, card Advanced. RimWorld 1.6 only, on by default.

Normally RimDroid emulates all of RimWorld, including the code of the game itself and of its mods. With this switch the game's and the mods' code runs directly on the phone's processor, and only the Unity engine is emulated. Simulation, loading and high game speeds get noticeably faster. For our testers loading got about twice as fast, and speed 3 is finally really faster than speed 2. The bigger the colony and the modlist, the bigger the difference.

  • If the game crashes twice in a row while starting, the launcher offers to turn native Mono off.
  • If something is wrong, just turn the switch off: the game goes back to the previous mode. Your saves are not affected, they load in both modes.

Getting the best performance

RimWorld is very demanding on the processor, and emulation adds to that. A fresh three-colonist start is light; a large, old colony with many pawns and mods is far heavier, and even a strong phone feels it.

  • Turn on your phone's game booster and set it to its highest-performance profile: Samsung Game Booster, Xiaomi/POCO Game Turbo, Realme/OPPO/OnePlus Game Space, vivo/iQOO Ultra Game Mode, Infinix/Tecno Game Mode.
  • Install a performance mod such as RocketMan. The processor is the limit, and these mods cut the cost of the simulation directly.
  • Set a Frame rate limit of 60 or 30, and on weaker phones try Texture compression: Low and a lower Render resolution.
  • Keep the colony and the mod list modest on weaker phones, and close background apps.
  • On weaker phones the game speed buttons may not change the frame rate at all. That is expected: the simulation, not the graphics, is the limit.

Known issues

Black screen after starting the game again

If you leave the game while it is still running and then tap ▶ again, the screen can stay black. Return to the running game from the recent-apps screen instead. If it is already black, close RimDroid completely (swipe it away in recent apps) and launch again.

Picture cut off at both sides (OPPO and other ColorOS phones)

The per-app display setting Hide camera shrinks the game and cuts off both sides. Fix: turn Hide camera off for RimDroid, keep Full screen on, close the app completely and launch again. The names of these settings vary between phones; search the phone's settings for "full screen".

Artifacts on older Mali GPUs

On phones with an older Mali GPU the picture may show artifacts that change from launch to launch. Try the MobileGlues renderer.

Reporting a problem

Open the side menu and tap Report a bug, then choose the instance where the problem happened. RimDroid attaches its logs and your phone's details to a message to us: pick your email app, describe the problem and tap Send. Report right after the problem happens, while the log still holds it. Export logs (ZIP) saves the same logs as a file, for example to attach to a GitHub issue.

The icons at the top of the side menu lead to new versions on GitHub and to RimDroid on X and Reddit.
