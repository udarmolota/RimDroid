快速开始

RimDroid 是一个启动器：它在 Android 上运行你自己的 RimWorld。 游戏本身不包含在内。

  1. 你需要在 Steam 或 GOG 上拥有 RimWorld。RimDroid 运行的是游戏的 Linux 版本，RimWorld 1.6；1.5 仍可照常运行（旧版），但新功能和修复只针对 1.6。
  2. 把游戏放进应用。用 Steam 的话，打开侧边菜单，点 Steam 下载：游戏会下载成 .zip，再点创建实例就能用它做出一个准备好的实例。GOG 和其他方式见 获取游戏。
  3. 实例就是一份安装好的游戏。每个实例在主屏幕上有自己的卡片， 齿轮图标后面是它自己的设置。你可以保留多个实例，比如 1.5 和 1.6 并存。
  4. 创建实例时，RimDroid 会检测手机的 GPU 并自动选择合适的图形驱动。
  5. 点卡片上的 ▶ 按钮。第一次启动会久一些，游戏需要准备文件。加载时不要按返回键。

需要 Android 11 或更新版本、64 位手机、至少 6 GB 内存（8 GB 以上玩得更舒服）， 以及 5–10 GB 可用存储空间。

每个界面顶部的 ? 会打开本页中关于该界面的部分。

实例卡片的 ⋮ 菜单里有添加到主屏幕：一个直接启动游戏、不经过启动器的快捷方式。

出了问题？见报告问题。

获取游戏

RimDroid 需要 RimWorld 的 Linux 版本，来自你拥有该游戏的商店。 选择下面任一方式。

1. 在应用内从 Steam 下载

  1. 打开侧边菜单，点 Steam 下载，游戏标签。
  2. 选择 RimWorld 1.6，或在应用提供时选择 RimWorld 1.7。 在 Steam 推出稳定的 1.7 之前，应用会下载 unstable 测试分支的最新构建。
  3. 用你的 Steam 账号登录。登录信息只发给 Steam，不会保存。 在 Steam 手机应用里确认登录，或输入 Steam 令牌验证码。
  4. 点下载。游戏会以 .zip 保存到 Download/RimDroid，文件名是它的 Steam 构建号 （需要所有文件访问权限）。如果这个构建已经在那里，就不会重复下载。
  5. 点创建实例：用这个 zip 创建新实例。以后也能用同一个 zip 再创建其他实例， 就像任何游戏 zip 一样。
  6. 如果下载中断，用同一个版本再次开始，会从中断处继续。

如果想要其他构建而不是默认构建，在高级字段里输入它的 Manifest ID （ID 列表见 SteamDB）。如果是 unstable 分支的构建，还要勾选 该 Manifest 属于 unstable 分支（测试版）。否则留空。

2. 从 GOG

  1. 打开侧边菜单，点登录 GOG。在 GOG 自己的页面上用 GOG 邮箱和密码登录： RimDroid 看不到你的密码。
  2. 通过关联账号（例如 Google）登录无法在应用内完成。 如果你平时是这样登录的，请先设置一个 GOG 密码：gog.com → 登录 → 重置密码。
  3. 点检查游戏库。RimWorld 会以卡片形式出现，DLC 列在它下面。
  4. 在游戏和每个想要的 DLC 上点下载。文件会依次下载到公共的 Download/RimDroid 文件夹；系统询问时请允许所有文件访问。 期间可以切换到其他应用。如果下载中断，再点一次按钮继续。
  5. 游戏下载完成后，它的按钮会变成创建实例。新实例会包含游戏和所有已经下载好的 DLC。
在电脑上

在 gog.com 的游戏库里下载 RimWorld 和你拥有的 DLC 的 Linux 安装程序（.sh 文件）。 把它们全部打包进一个 .zip 压缩包，复制到手机上，按 从 .zip 压缩包的说明添加。之所以需要 .zip， 是因为文件管理器不能可靠地把单独的 .sh 文件交给应用。

3. 从 .zip 压缩包

打开侧边菜单，点添加游戏实例，或主屏幕顶部的 +。输入名称，点选择 ZIP 文件， 选中压缩包，然后点安装。

  • .zip 里可以是 RimWorld 的 Linux 版（带 RimWorldLinux 文件的那个， 外面套一层文件夹也没关系，RimDroid 能找到），或者 GOG 的游戏和 DLC 的 .sh 安装程序。
  • 名称请简短：拉丁字母和数字，最多 40 个字符。
  • 不必保留 .zip，但留着以后重装或创建同版本的另一个实例会方便。

DLC

  • 从 Steam：在 Steam 下载的 DLC 标签里勾选你的账号拥有的 DLC， 点下载所选 DLC。每个 DLC 保存为 Download/RimDroid 里的一个 .zip。
  • 从 GOG：在登录 GOG里从它的卡片下载，然后在同一张卡片上点安装。 创建实例之前下载的 DLC 会自动包含进实例。
  • 安装 DLC 文件：打开侧边菜单，点安装模组／DLC，选择文件和实例， 打开 DLC 标签，点安装。GOG 安装程序会被自动识别。
  • DLC 必须与实例的游戏版本匹配：1.6 的 DLC 装进 1.6 的实例。 所以安装界面总会让你选择实例。

模组

  • Steam 下载的模组标签按 ID 下载创意工坊模组：工坊链接末尾的数字 （…/filedetails/?id=数字）。不需要登录 Steam；多个 ID 用空格分隔。 每个模组保存为 Download/RimDroid 里的一个 .zip。同一标签上的 通过浏览器下载会打开一个第三方网站。
  • 在侧边菜单的安装模组／DLC，模组标签里安装。RimDroid 会在任意 .zip 里 找到模组的真正文件夹（含 About/About.xml 的那个）。
  • 创意工坊合集也一样：粘贴合集的链接或 ID，就会下载其中的所有模组。
  • 侧边菜单的 Steam 创意工坊会打开 RimWorld 创意工坊本身，带有 Steam 的搜索和筛选。 点击模组或合集卡片上的 ↓（或在其页面点加入队列），再点下载：队列会交给 Steam 下载，按上面的方式下载。A−／A+ 调整文字大小。在安装模组／DLC 里可以一次选择多个 .zip。
  • 侧边菜单的模组列出实例的模组：上方是按加载顺序排列的已启用，下方是 未启用，并可搜索。开关用于启用或停用模组，垃圾桶删除下载的模组，点按查看详情。 不适用于 1.6 表示模组未声明支持此游戏版本；未安装 表示在列表中但缺少文件夹。 请先关闭游戏：游戏运行时无法更改列表。
  • 排序按模组作者的要求排列已启用的模组（模组依赖的模组先加载）：先 Harmony，再 Core 和 DLC。在做任何更改前，会显示将移动多少个模组，以及缺少（附创意工坊编号）或已停用的 必需模组。要手动移动模组，按住 ≡ 拖动；长按可选择移到最前／移到最后。
  • 复制按钮（两张纸）把实例中下载的模组复制到另一个实例；对方已有的模组保持不变。勾选 同时以相同顺序启用相同的模组，还会把模组列表一起带过去（对方没有的 DLC 会被跳过）。 排序还会使用玩家为未声明规则的模组收集的加载顺序规则（RimSort 的 Community Rules Database）。
  • 需要 Harmony 的模组可以用：像在电脑上一样，加上 Harmony 模组本身。
  • 最多约 50 个模组的列表经过测试。更大的列表尚未测试。
  • 实例卡片 ⋮ 菜单里的管理存储会在手机的文件管理器中打开该实例的文件夹， 方便手动添加或删除文件。
  • 如果中文、日文或韩文不显示，请安装 RimDroidCJKmod 字体模组：用安装模组／DLC的模组标签添加这个 .zip，然后在游戏的模组菜单里启用。 它不依赖其他模组。

渲染器与驱动

渲染器把游戏的桌面图形转换给 Android。在实例设置（齿轮图标）的视频卡片里选择。

Zink ZFA（Vulkan）

默认且推荐的渲染器。它通过手机的 Vulkan 驱动绘制，驱动就在它下方选择。

MobileGlues（不用 Vulkan）

改为通过手机的 OpenGL ES 驱动绘制，完全不需要 Vulkan。实验性功能。 如果 Zink 黑屏或画面错乱，可以试试它；在没有骁龙（Adreno）GPU 的手机上可能有帮助。

使用这个渲染器时，每次启动都要把游戏纹理转换成手机的格式，多花 10–20 秒加载时间。 侧边菜单设置里的纹理缓存（MobileGlues）会把转换好的纹理保存在磁盘上 （保留转换后的纹理，默认开启），从第二次启动起游戏进入菜单会更快。 缓存由所有实例共用，带全部 DLC 时占几百 MB；清除会删除它，下次启动会重新填充。

Vulkan 驱动（用于 Zink）

创建实例时 RimDroid 会为你的 GPU 选择驱动，推荐驱动（检测 GPU）会再做一次同样的事。 如果画面不对或一直黑屏，换一个试试。

  • 系统（手机驱动）：手机自带的驱动。适用于任何 GPU，没有骁龙（Adreno）GPU 的手机应选它。
  • Turnip 和 Freedreno：面向骁龙（Adreno）GPU 的开源驱动， 各自对应列表中标明的 GPU 代际（6xx、7xx、8xx、830/840）。
  • Turnip Adreno 7XX_new (v26.2)：Adreno 7xx 上黑屏时第一个该试的。
  • Turnip Adreno 6xx (legacy)：用于较旧的 Adreno 6xx GPU，比如骁龙 685 里的那颗。
  • 自定义驱动（已导入）：你自己的驱动。在侧边菜单的自定义 Vulkan 驱动里导入 （.so 文件或 AdrenoTools 的 .zip）。之后由所有实例共用。

画面与帧率

这些都在实例设置（齿轮图标）里。

  • 渲染分辨率：分辨率越低，弱 GPU 上 FPS 越高，界面也越大； 以手机自身分辨率全屏最清晰。黑边 1366×768 最快。
  • 纹理压缩缩小纹理以节省内存并提高 FPS，在较弱的手机上加载多个 DLC 时必需。 主要影响植物和资源；殖民者和动物不受影响。低是不错的平衡， 极低更快一点，但植物会显得模糊。
  • 文字大小（仅限 RimWorld 1.7）：100 / 120 / 130 / 140%，默认 120。只放大文字， 窗口和按钮大小不变；在 130–140% 时，窄栏中的部分文字可能放不下。
  • 游戏内显示：FPS 在左上角显示帧率；完整信息在顶部显示一条状态栏， 含 GPU 和 CPU 负载、内存、功耗、温度和 FPS 曲线——方便看出是什么拖慢了游戏。下次启动生效。
  • 帧率上限（30、60 或不限制）可以减少波动，把更多处理器资源留给游戏， 在较弱的手机上能提高游戏速度。如果计数器跳动不停，试试 60 或 30。

控制

触控

  • 点一下是左键点击。
  • 手指按住不动片刻是右键点击，用来下达“移动到这里”之类的命令。短暂震动表示已触发。
  • 双指捏合缩放。
  • 用左摇杆移动视角。要改为单指拖动地图，在实例设置里打开单指拖动地图平移视角。

屏幕控件

  • 默认布局有一个鼠标光标摇杆、一个视角摇杆、左键和右键、菜单（Esc）、暂停（空格）、 游戏速度 1–3、建筑（Tab）、工作、日程和分配标签（F1–F3）、旋转（E）、 用于排队命令的 Shift，以及游戏快捷键 B、H 和 L。按钮显示图标；眼睛按钮隐藏／显示控件， 键盘按钮打开手机键盘。
  • 在侧边菜单的编辑屏幕控件里修改（有多个实例时会询问是哪个）：点一个元素选中它， 拖动来移动。添加创建绑定到任意按键或鼠标动作的按钮；重置恢复默认布局。 网格按钮在网格：关（自由放置）、网格：小（精细网格，精确放置）和 网格：大（粗网格，让按钮整齐对齐）之间切换。
  • 侧边菜单的按钮图标用图片代替按钮文字：选择实例，在图标包旁边按应用， 每个按钮都会得到其动作对应的图标。RimDroid 自带一个图标包；导入图标包（zip）添加你自己的， 图标包旁边的移除会去掉它的图标、恢复文字。“应用”在不会产生任何改变时显示为灰色。 在编辑器里，图标对打开的布局做同样的事，每个按钮自己的面板里有选择图标和移除图标。 图标包是一个 PNG 图片的 .zip，透明背景白色图案，按动作命名：click, right_click, middle_click, zoom_in, zoom_out, menu, pause, accept, speed_1 到 speed_4, architect, work, schedule, assign, animals, wildlife, research, quests, world, history, rotate_left, rotate_right, queue, forbid, prev_colonist, next_colonist, camera_up, camera_down, camera_left, camera_right, keyboard, toggle_controls。可选的 pack.json 给它命名： {"format": 1, "name": "My icons"}；彩色图片请加上 "tint": false。
  • 侧边菜单的导入／导出控件把实例的布局保存为 .json 文件或从文件加载。 文件里不含图标：在另一台手机上请在那里应用图标包。

输入文字

要在游戏里输入文字，比如给殖民者改名，先点文本框，再点键盘按钮： 手机键盘会打开，输入的内容进入游戏。再点一次关闭。 仅支持 RimWorld 1.6，且只能输入拉丁字母。

手柄、鼠标和键盘

  • 实体手柄可用：右摇杆移动光标，左摇杆移动视角，扳机键点击，肩键缩放。 如果按键错位，在实例设置的手柄映射里修正：点开始，为每个动作按下你想用的按键。
  • 实体鼠标和键盘也可以用。
  • 游戏始终横屏运行。画面翻转（180°）用于把手机反着夹的手柄或支架。下次启动生效。

存档与设置

  • 侧边菜单的导入 / 导出存档以 .zip 形式把实例的存档导出和导入： 用于备份，或转移到另一个实例或手机。
  • 导入 / 导出设置对游戏设置做同样的事：选项、按键绑定、模组列表和模组设置。
  • Steam 云存档：如果你也在电脑上通过 Steam 玩 RimWorld，它会把云存档拉到手机上， 并把手机的存档发回去。登录在 Steam 手机应用里确认，所以那里必须开启 Steam 令牌。 两边都有同名存档时，由你选择保留哪一个。发送前请关闭游戏。

兼容模式

在实例设置的高级卡片里（点标题展开）。游戏无法启动时打开：黑屏，或卡在加载。 开启后游戏会稍慢，不需要时请关掉。这是一个变通方案，不一定对每台手机都有效。

同一卡片里还有调试模式（写更详细的日志）和环境变量。 除非我们请你修改，否则两者都请保持原样。

引擎

在实例设置（齿轮图标）里，第一张卡片。仅限 RimWorld 1.6：1.5 的实例始终以第一种方式运行。

  • 完全模拟（box64）：一切通过 x86 模拟运行。兼容性最好，速度最慢。
  • box64 + 原生 Mono：引擎被模拟，游戏和模组的代码原生运行。更快；以前的默认选项。
  • 原生引擎（实验性）：为 Android 构建的游戏引擎，无需模拟。最快，占用内存最少。仅支持 Vulkan。 新实例默认使用它；已经玩过的实例保持原来的引擎，直到你在这里切换——启动器会提示一次有新引擎可用。

原生引擎的不同之处：

  • 渲染器和 Vulkan 驱动设置不起作用：它始终直接通过 Vulkan 绘制。引擎选项下方的 Vulkan 兼容性： “自动”会在已知需要它的 GPU（Mali-G615）上开启；如果画面在标志或菜单处卡住而游戏仍在运行，请开启。
  • 纹理压缩（无 / 低 / 极低）在这里同样有效，但只缩小大纹理；图标和殖民者保持清晰。 新实例默认为“低”：8 GB 内存的手机加很多模组时，没有它游戏可能无法加载。
  • 分辨率预设和 box64 上一样：黑边 1366×768 把游戏画在带黑边的 16:9 框里。
  • 鼠标滚轮可以缩放地图和滚动列表，和电脑上一样（列表需要 Harmony 模组）。双指捏合和 Zoom in / Zoom out 按钮作用相同。
  • 启动时可能出现“无法初始化 Steam”的提示：点 Ignore。
  • 如果出了问题，在这里切回 box64 + 原生 Mono；三种引擎的存档是通用的。

报告问题会附上原生引擎自己的日志。

获得最佳性能

RimWorld 对处理器要求很高，模拟又增加了负担。三个殖民者的新开局很轻松； 一个有很多殖民者和模组的大型老殖民地要重得多，强力手机也能感觉到。

  • 打开手机的游戏加速并设为最高性能档：三星 Game Booster、小米/POCO 游戏加速、 Realme/OPPO/一加游戏空间、vivo/iQOO 电竞模式、Infinix/Tecno 游戏模式。
  • 安装 RocketMan 之类的性能模组。瓶颈在处理器，这些模组直接减少模拟运算的开销。
  • 把帧率上限设为 60 或 30，较弱的手机上试试纹理压缩：低和更低的渲染分辨率。
  • 较弱的手机上殖民地和模组列表都别太大，并关闭后台应用。
  • 较弱的手机上，游戏速度按钮可能完全不改变帧率。这是正常的：瓶颈在模拟运算，不在图形。

已知问题

再次启动游戏后黑屏

如果游戏还在运行时你退出了它，然后又点 ▶，屏幕可能一直黑着。 请改为从最近任务界面回到正在运行的游戏。如果已经黑屏，彻底关闭 RimDroid （在最近任务里划掉）再重新启动。

画面两侧被裁掉（OPPO 及其他 ColorOS 手机）

按应用的显示设置隐藏摄像头会缩小游戏并裁掉两侧。 解决：为 RimDroid 关闭隐藏摄像头，保持全屏开启，彻底关闭应用再启动。 这些设置在不同手机上名称不同；在手机设置里搜索“全屏”。

较旧的 Mali GPU 上画面异常

在较旧的 Mali GPU 手机上，画面可能出现每次启动都不一样的异常。试试 MobileGlues 渲染器。

报告问题

打开侧边菜单，点报告问题，然后选择出问题的实例。RimDroid 会把日志和手机信息 附在一封给我们的邮件里：选择你的邮件应用，描述问题，点发送。 请在问题发生后尽快报告，趁日志里还有记录。列表里只有邮件应用。设备上没有邮件应用？ 同一界面上的将报告保存为文件会把同样的日志保存为文件（也可用于 GitHub issue）： 从任意其他设备把它发送到那里显示的地址。

侧边菜单顶部的图标通向 GitHub 上的新版本以及 RimDroid 的 X 和 Reddit。
